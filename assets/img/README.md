# Drop your logo here

The site looks for **`logo.png`** in this directory (referenced as
`assets/img/logo.png` from every page).

- Recommended size: `512×512` (rounded square or transparent background).
- A square PNG works best for the nav and the favicon.

If `logo.png` is missing, an inline SVG fallback (`logo.svg`) carrying the
greek τ mark is shown — the site never renders broken.

You can also drop:

- `og-cover.png` (1200×630) — used as the link-preview image when the site
  is shared on social platforms.
